# C11-342: Test: GhosttySurfaceOverlayTests flag-banner z-order waits a fixed 50ms for an overlay mounted via main.async (flaky under load)

Found in the C11-337 R8 test-fix attribution. Passes before the rename (c43800563f) and 3/3 isolated at main and at #606's head; fails only in loaded full c11-unit runs on Atlas (load 51-58), where the overlay mount takes about 0.61s instead of 0.05s. The overlay mounts via DispatchQueue.main.async and the test waits only 50ms. Fix: wait on the condition (XCTestExpectation or waitUntil) instead of a fixed delay. Not a product bug.
