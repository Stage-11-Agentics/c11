The earlier payload contained an additional empty dirty-option space, with the same routing values. The candidate payload omitted dirty status. A separate manual control sent:

Both servers acknowledged OK, and their sidebar immediately became fixture-next clean. Both commits exited 0 with no index.lock error. This control isolates the routing seam; it is not automatic-path PASS evidence.

Source corroborates the runtime: Sources/GhosttyTerminalView.swift:3536 injects the tab UUID into CMUX_TAB_ID; Resources/shell-integration/cmux-zsh-integration.zsh:253 forwards that value in --tab; Sources/TerminalController.swift:670 parses --tab as workspace; Sources/SocketHandlers/SocketDispatch.swift:489 looks up that workspace and silently returns when it does not exist. The injected-tab value dates to commit bcebbbc2035; the routing-handler assumption exists in the approved earlier build. Candidate/earlier execution, not source inspection alone, establishes the pre-existing classification.
