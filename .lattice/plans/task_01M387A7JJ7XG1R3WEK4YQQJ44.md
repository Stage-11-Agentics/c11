# C11-232: Event log retention by time with title-churn deduplication

Why: Sources/Events/EventLog.swift rotates at an 8 MB cap and keeps one generation. Probe 1 run B found a spinner title in an unrelated workspace filled the backup in 65 minutes and erased the first six hours of the C11-188 run. Deliverable: (1) retention by age (default 14 days, configurable) with size as a secondary bound, several generations; (2) title and description change events coalesced when the same surface changes value more than N times per minute (emit first, last, and a count), so a spinner cannot flood the log; (3) log.rotated marker preserved; docs updated and synced; a test through the real EventLog that writes a churn burst and asserts retention. Out of scope: changing the envelope schema.
