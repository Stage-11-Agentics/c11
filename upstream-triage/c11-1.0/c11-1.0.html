02Verdict

c11 1.0 is a reliability and attention release with a real lifecycle journal and analytics at its core. It makes the room trustworthy for 40 agents: honest agent status backed by a durable record, one list of what is waiting on you, workspace groups, focus history agents can read, safer CLI targeting, and the upstream hang and crash fixes c11 shares.

The journal is in

  • Both auditors wanted the durable journal in 1.x. Atin ruled it in, for analytics. That gives it the consumer the auditors said it lacked.
  • SQLite journal with an NDJSON export (D3, lead's call: c11 already links SQLite).
  • The C11-188 guardrails stay: a cross-family plan review before code, acceptance tied to real incidents, a hard cap of three review cycles.

Remote hosts move to 1.1

  • Prime sandboxes as real c11 tabs, per-tab hosts, the Go terminal holder: all 1.1, spike and build (D9).
  • No lid-close work (D10). Long-lived agents run in Atlas's own c11; Caffeine keeps Macs awake.
  • 1.0 keeps one remote item: a smoke test of c11 ssh after #490, and a truthful skill.

07Waves

No calendar. The run goes in waves, aiming to finish close to overnight.

Opus 5.5 orchestrates on Bravo, from Atlas's c11. Every ticket owner is Codex or Grok and plans its own ticket just in time. Only the journal spec gets an independent plan review. Codex is the tight resource, so Grok takes the scoped work and Codex reviews it.

08Red team

Each auditor made the strongest honest case against the two biggest bets. One verdict was overruled, one held.

Against the event journal: overruled

  • Each incident has a smaller fix. The ack, spool and drain are C11-188's markers under new names. (Fable)
  • A newest-sequence fold does not fix a late hook: Stop gets 10, a delayed PreToolUse gets 11, and the agent reads "working" again. (Astra)
  • History had no consumer. (Fable)

Atin ruled it in for analytics, which is the consumer. The spec must answer the late-hook case and keep the guardrails.

Against remote hosts: upheld

  • #490 just removed the command channel; rebuilding one deserves its own release and security review. (Fable)
  • The terminal holder is a port of a 2,637-line Go file cmux is still patching. (Fable)
  • Three products in one: a durable remote terminal, trusted telemetry, session migration. (Astra)

Moved to 1.1, spike and build, Prime sandboxes included.

10Out of scope

Ruled out: restore accounts (D14), stable tab numbers (D15), keybinding change (D16), automatic naming (D18), sidebar rewrite (D21), upstream Ghostty offer (D23), separate point releases (D25).
