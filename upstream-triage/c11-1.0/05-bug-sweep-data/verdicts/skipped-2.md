## Top findings

**Closed-window retention, 8513, high.** The main window owns its hosting content, while ContentView stores the same NSWindow strongly in state. Closing unregisters the context without breaking that ownership chain. The shared cycle is visible in source; retained memory growth is inferred rather than measured. Repeated window turnover over multi-day sessions makes this worth an adapted fix. It does not explain the August mailbox deadlock.

**Notification loss on restart, cl-e4856922, high.** c11 initializes an empty notification store and omits notification records from the session snapshot. Persisted manual-unread flags do not preserve the messages or their unread state. Restart is part of Atin's normal recovery workflow, so this loses useful agent completion history even when workspace restoration succeeds. Implement persistence using c11's stable workspace and surface identities.

**Agent command targeting, 4042, 7749, 13843, and 4812, med.** Workspace creation omits the caller's window context; legacy window commands send typed handles to UUID-only parsers; reorder validation counts resolved selectors rather than supplied selectors. External path opening also depends on a socket that rejects external descendants under the default policy. These are distinct, small-to-medium command fixes. The separate 14706 spot-check remains higher risk because an empty explicit close target can fall through to the focused surface.

**Updater callback loss, 12283, med.** Delaying a callback-bearing update state transfers Sparkle's required reply into a cancellable work item. Cancellation or a changed-state guard discards the callback. Preserve callback completion on every cancellation path. The stale override in 3833 and old Sparkle pin in spot-check 6678 are separate updater issues, not explanations for this callback bug.

**Costs and controls at fleet size.** PR 2466's remaining c11 overlap is redundant nested-shell HEAD watchers, not its upstream clock mismatch. PR 8296's unbounded bulk-close text survives in c11's custom overlay and can exceed the viewport with many workspace titles. The 6801 and 2328 spot-checks confirm layout/sidebar work that scales with workspaces and can contribute to [known problem 2](../brief-skipped-2.md). Port 6801's retry changes together with observer removal; do not treat one deleted observer as the complete repair.
