# C11-243: Tab last-seen tracking: record when the operator last looked at each tab

Record, per tab, when the operator last looked at it: stamp when a tab becomes the visible tab of the focused area in the key window, and when it stops being visible (area unfocused, tab switched, workspace switched, window resigns key, app deactivated). Persist it with the session snapshot. Expose it next to the existing tab timestamps (createdAt, last activity) so the tab sheet can show a Seen clock, and read it back through the socket/CLI (for example in get-metadata or tree --json) so agents can use it. Out of scope: the sheet UI itself; the tab sheet round-three PR adds a Seen clock column that reads this once it lands. Design reference: design/tab-bar-qol/prototype-v3.html (the '+ Seen' clock order) on the tab-bar-qol branch. Requested by Atin 2026-09-29.
