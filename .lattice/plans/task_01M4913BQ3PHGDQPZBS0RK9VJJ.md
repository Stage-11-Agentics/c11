# C11-343: Tests: MenuBarExtraAttentionTests leak state through a shared store (order-dependent failures in full c11-unit runs)

Found in the C11-337 host-suite attribution (evidence: c11-worktrees/signoff-feedback/panel-rename/evidence/host-suite-attribution.md). In full c11-unit runs on Atlas, MenuBarExtraAttentionTests.testLiveIndexRefreshesRaiseReasonChangeLowerAndCloseWithoutRoutineNotice (NotificationAndMenuBarTests.swift:1072-1075) and testLiveSuppressionHidesUnflaggedCompletionAndFlagOverridesIt (:1157) fail; both pass when the class runs alone at cde01d1571 (signoff-1-1), 2f6a4db8d7 and 1eaed8a68d. testFlagRowsUseExistingOrderAndExactTargetsAndRoutineActionsDoNotLowerFlags and testFeedAskRefreshAndShortcutPreservationWithoutRoutineNotice show the same order dependence. Not quarantined, so this is a likely source of red hourly host gates. Fix: isolate the shared stores per test (inject, or reset in setUp), then confirm the full suite passes twice.
