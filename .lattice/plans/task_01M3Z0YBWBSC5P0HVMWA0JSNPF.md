# C11-321: Hourly CI skips the run when main has not changed since the last completed run

Atin, 2026-10-02: keep CI on GitHub-hosted runners (no Atlas self-hosted runner for now; Atlas carries other load), but stop paying for idle hours. ci-hourly.yml (and the hourly compat/GhosttyKit schedules) run every hour on macos-15-xlarge, which GitHub bills per minute even on a public repo, whether or not main moved. Add a cheap first job (ubuntu) that compares main's HEAD with the head SHA of the last completed scheduled run of the same workflow (gh api actions/runs), and skips the macOS job when they match. workflow_dispatch always runs. Keep the hourly-red-main fix-forward rule unchanged. Accept: an hour with no new commit on main shows a skipped macOS job; an hour after a merge runs it; a manual dispatch always runs.
