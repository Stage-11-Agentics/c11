# C11-201: A button: resolverCwdForAgentLaunch ignores workspace.rootDirectory (diverges from CLI after C11-194)

Found by the C11-195 trident plan review (pack: notes/trident-review-C11-195-plan-pack-20260806-1405/, item I6). Workspace.swift:~12488 resolves project .c11/agents.json via resolverCwdForAgentLaunch(), which reads the focused panel's directory and never consults workspace.rootDirectory. Once C11-194 lands, a workspace with an explicit root resolves project config from the ROOT when launched via CLI but from the shell's wandered cwd when launched via the A button — same operator, same workspace, two different agents. Likely a one-line fix: put rootDirectory at the front of resolverCwdForAgentLaunch()'s ladder. Verified against fix/C11-193-launch-agent-cwd by 4 of 9 reviewers.
