## Implementation and coexistence

1. `Sources/AppDelegate.swift`: extract a small nonisolated candidate/policy helper (bundle ID, current/candidate PID and launch date, canonical candidate bundle/executable URL). A same-ID main app is a candidate even from a different bundle directory. Select the oldest live app (launch date, deterministic PID tie-break); missing launch-date metadata prefers the established other process. Current PID, terminated processes, different bundle IDs and non-main executables do not conflict. Retain explicit CLI exclusion when resolving incomplete helper metadata.
2. `Sources/c11App.swift:init`: call startup arbitration immediately after applying the launch manifest and checking the required debug tag, before creating WorkspaceManager, configuring Ghostty, preparing startup snapshots, arming sentinels or starting sockets. Audit property initialization so no persistence/restore work escapes ahead of the check. Remove the late destructive enforcement. Respect normal XCTest isolation; provide a dedicated policy test seam rather than changing production behavior to satisfy mocks.
3. On conflict, activate the incumbent for this explicit user app launch, log a short diagnostic, and `_exit(0)` the NEW process without normal termination/autosave hooks. Do not call terminate/forceTerminate on the incumbent. Log to existing diagnostics/stderr, not a modal or new product UI.
4. `observeDuplicateLaunches`: use the same identity filter; the incumbent never signals a newcomer. A newer cooperating process arbitrates and exits itself. If an observer rechecks arbitration to resolve near-simultaneous startup, only the losing process can exit itself. Do not add replacement overrides or a new persistent instance registry.
5. Tagged builds use `com.stage11.c11.debug.<normalized-tag>` (`reload.sh:275`, launcher `:128`), distinct from `com.stage11.c11`. Different tags and production therefore coexist. Same tag/copy yields. C11-244 is a Tart guest OS (`sandbox-up.sh` copies the app inside guest; sandbox runtime enters its own Aqua session); host process enumeration cannot see guest applications even when bundle IDs match. Do not relax matching for guests or change sandbox scripts.
6. Add pure executable/candidate policy tests (`c11Tests/SingleInstancePolicyTests.swift`, logic-target membership as needed) and an isolated packaged-app launch harness `tests_v2/test_single_instance_yield.py`. No source grep tests. No socket protocol or installed skill changes expected.
