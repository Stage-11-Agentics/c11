Design directions

Six skins over one faithful c11 layout. The void stays dominant; the accent stays singular. What changes is register.

The constants

  • Void-dominant ground state, elevated surfaces barely above it
  • One accent color, entering like signal into silence
  • Monospace for the engine room, system font for the chrome

The variables

  • Obsidian — ancient-future, bioluminescent edges
  • Blueprint — schematic, every pane a coordinate
  • Command Deck — fleet HUD, telemetry forward

Flip the switcher above to compare. The content never moves — only the language around it.

Floor plan
Void + Gold — the canonical Stage 11 register: pure void, a single gold signal, monospace engine room. A polished take on c11 today.
