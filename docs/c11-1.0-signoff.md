# c11 1.0 sign-off checklist

**Failure:** Add `FAIL: <what you saw>` beside the step. Nothing else.

## Setup

- App: `~/Library/Developer/Xcode/DerivedData/c11-signoff-1-1/Build/Products/Debug/c11 DEV signoff-1-1.app`. It runs beside normal c11 with its own settings, bundle ID `com.stage11.c11.debug.signoff.1.1`, and socket `/tmp/c11-debug-signoff-1-1.sock`.
- Launch from the c11 checkout: `./scripts/launch-tagged-automation.sh signoff-1-1 --qa fresh`.
- Point this shell's CLI at the sign-off app: `export C11_SOCKET=/tmp/c11-debug-signoff-1-1.sock`; then run `c11 <command>`.
- Build: tag `signoff-1-1`; main `cde01d1571`; version `0.67.0`.

## Steps

1. **[ ] Confirm the tagged build (C11-292).** Run `c11 doctor --json` and open About in the sign-off app. **See:** tag, app path, and version match Setup.

2. **[ ] Read and clear a terminal selection (C11-282).** Print `SELECTIONFIXTURE`, select it, then run `c11 read-selection --workspace <ws> --tab <tab> --json` from another tab. Clear the selection and run it again. **See:** the first result has the selected text and matching base64; the second has `has_selection: false` and empty text, with c11 still responsive.

3. **[ ] Check the large-selection limit (C11-282).** Print `1_100_000` characters with `python3 -c 'print("x" * 1_100_000)'`, select the output, and run `c11 read-selection --workspace <ws> --tab <tab> --json`. **See:** `truncated: true`, valid UTF-8, no more than 1 MiB, and matching decoded base64.

4. **[ ] Keep window-scoped reads and sends in their target (C11-283).** Open sign-off windows A and B with different markers, then make A key. From A, read B with `c11 --window <B> read-screen --tab <B-tab>`; try an invalid window and a send scoped to B but aimed at A. **See:** invalid and mismatched targets fail without typing, and A stays key until the explicit `c11 focus-window --window <B>`.

5. **[ ] Resize without changing focus (C11-286).** Put Finder in front, then run `c11 resize-window --window <window> 1200 800` on a second sign-off window. **See:** Finder stays frontmost, the key c11 window is unchanged, the resized window keeps its top-left point, and the applied size matches the response or its clamp.

6. **[ ] Recover a crashed browser surface (C11-287).** In a sign-off terminal, run `mkdir -p /tmp/c11-287`, then `printf '%s\n' '<!doctype html><title>C11-287</title><body style="font:40px sans-serif">C11_287_REPAINT_MARKER</body>' > /tmp/c11-287/index.html`. Run `python3 -m http.server 19287 --bind 127.0.0.1 --directory /tmp/c11-287`. Open `http://127.0.0.1:19287/`, call `c11 rpc debug.browser.simulate_web_content_termination '{"workspace_id":"<ws-uuid>","tab_id":"<browser-tab-uuid>"}'`, then run `c11 resize-pane --workspace <ws> --pane <pane> -L --amount 60`. **See:** the RPC returns `scheduled: true`, the same page visibly repaints the full marker, and the terminal still accepts input.

7. **[ ] Import synthetic Chrome history (C11-288).** Skip this on this Mac and write `SKIP: no isolated synthetic Chrome source`. Never select or import a real browser profile. **See:** the skipped check is clearly marked.

8. **[ ] Check browser-profile isolation (C11-289).** Start the synthetic cookie page with `python3 scripts/c11-288-seed-import-fixtures.py --serve`. In the sign-off browser, visit `http://127.0.0.1:19288/c11-288` in Default and a new profile named `c11-289-synthetic`; set `c11_288=synthetic` in both with `c11 browser --tab <tab> eval 'document.cookie="c11_288=synthetic; path=/"'`. Close every tab using the named profile before running `c11 browser profiles clear <profile-id> --yes`, then reopen it. **See:** the named profile is signed out, Default stays signed in, focus is unchanged, and no dialog appears.

9. **[ ] Do the C11-261 workspace-groups sign-off (C11-261).** In `docs/groups-signoff.md`, complete only operator checks H1-H3: confirm the tagged window, walk C1-C3, then run scoped cleanup and quit. The automated runner was the agent's job. **See:** the tag matches Setup, the group interactions work, and the normal c11 session is untouched.

10. **[ ] Observe waiting and flag behavior (C11-263, C11-274).** In your logged-in Claude Code tab, ask it to write `synthetic` to `/tmp/c11-292-check.txt` in normal permission mode. Leave approval open for two seconds, then approve it. In a separate bypass-mode turn, ask Claude Code: `Draft a one-step plan for printing 2+2, then call ExitPlanMode.` Raise one flag on your Claude tab and one on your Codex tab with `c11 raise-flag --tab <tab> "Synthetic flag"`; lower one with `c11 lower-flag --tab <tab>`. **See:** c11 shows waiting before approval and does not answer for you; the menu-bar flag remains visible with no routine unread, and the other flag stays raised.

11. **[ ] Open a typed ask without answering it (C11-264).** In your logged-in Claude Code tab, ask: `Use AskUserQuestion once to ask me whether I choose A or B, then wait.` Run `c11 feed list --json`, then `c11 feed open <tab>`. **See:** the row has the right type, its exact tab opens, and the question is still unanswered.

12. **[ ] Check attention order and counts (C11-265).** Use the step 11 prompt in two logged-in Claude Code tabs to create one unanswered A/B question each. Raise one flag on each tab with `c11 raise-flag --tab <tab> "Synthetic flag"`. Finish a short turn in your logged-in Codex tab and leave it unread. Open Feed, compare it with `c11 feed list --scope all --json`, then use Jump to Unread. **See:** flags precede asks and unread completions, counts stay distinct, the completion-only tab remains reachable, and c11 does not activate itself.

13. **[ ] Drive the Command-I quick view (C11-266).** Leave draft text in a terminal. First press Command-I, switch Asks/Turns, select a row, and press Return. Then focus the draft terminal, reopen Command-I, and press Escape as a separate check. **See:** Return opens the row without sending; Escape returns to the draft with its text intact.

14. **[ ] Answer a Feed row and check refusals (C11-268, additions 80-82).** In your logged-in Codex tab, finish a short turn and leave the prompt empty. Confirm `c11 feed list --scope all --json` shows its `turn_end` row, then run `c11 feed answer <codex-tab> --text "continue with the next step" --json`. After that turn finishes, try `c11 feed answer <codex-tab> --text $'line one\nline two' --json`. **See:** the first line is delivered and submitted; the second command exits with `multiline_unsupported` and leaves the prompt unchanged. Continue straight on: type `draft text` without Return and try Feed answer again. It should exit with `input_guard_refused` and preserve the draft.

15. **[ ] Resume prior blocked evidence (C11-273).** In your logged-in Claude Code tab, ask one A/B question with AskUserQuestion and leave it unanswered. Record its tab, quit the sign-off app, and relaunch with `./scripts/launch-tagged-automation.sh signoff-1-1 --qa resume`. **See:** the same ask returns as unconfirmed, its old run is not live, and the sidebar and Jump to Unread still reach it.

16. **[ ] Check clean and interrupted restore (C11-311).** Use two existing terminal areas if the sign-off session has them; create them only if fewer than two exist. Put a marker in each and wait for autosave. Close B and note the smaller layout. On this Mac, stop only the exact signoff-1-1 PID, relaunch with `./scripts/launch-tagged-automation.sh signoff-1-1 --qa resume`, and verify the richer layout returns. Recreate the smaller layout, choose Quit from the tagged app menu, choose Quit in the confirmation if it appears, and verify the exact tagged PID exits before relaunching with resume. **See:** the smaller layout returns after clean quit. If Quit is disabled or the PID remains, mark `BLOCKED` and stop; do not infer a restore failure.

17. **[ ] Correlate an operator response with the journal (C11-231).** Create a normal-mode Claude Code permission request with the harmless write from step 10. Open its Feed row and approve it with Return in the Claude terminal. Run `c11 agents --json` and `c11 journal query --workspace <ws> --from <start> --to <end> --json`. **See:** the same ask resolves with an `operator_response`, and an independent unread completion remains reachable.

18. **[ ] Check focus history through the visible path (C11-262).** Visit two tabs, run `c11 history`, then `c11 history back`. Type a short command in a terminal. **See:** history returns to the previous tab and typing adds no history row.

19. **[ ] Preserve the selected workspace against agent switching (C11-323).** From your logged-in Codex tab in the sign-off app, run `c11 select-workspace --workspace <W2>` while W1 is selected. Then use Return in Feed or the sidebar to switch deliberately. **See:** the command returns `workspace_switch_blocked`, W1 stays selected, c11 stays in the background, and the user action switches to W2.

20. **[ ] Undo the tab-rail tip cleanly (C11-249).** Overflow a Tabs strip, run `defaults write com.stage11.c11.debug.signoff.1.1 c11.tabRailTip.forceOffer -bool true`, and change tabs. While the tip is open, open the count-cell tab sheet, close it, and re-offer the tip. Choose Try Rail, then Undo; switch to Rail in Settings and resize the window and divider. Run `defaults delete com.stage11.c11.debug.signoff.1.1 c11.tabRailTip.forceOffer`. **See:** the tip tracks the count-cell anchor and Undo returns the setting to Tabs; selecting Rail later reopens that area's rail, the known C11-330 issue.

21. **[ ] Close a busy window without a stray terminal (C11-250, C11-311).** In W2, run `sleep 600` and press Control+Command+W. Choose Close in the confirmation sheet; do not leave it unanswered and expect the red close control to bypass it. **See:** W2 closes, the app remains open, and no new window or terminal appears in W1. Separately, with the default last-tab setting, press Command+W on an idle last terminal and confirm its workspace closes without a replacement terminal.

22. **[ ] Show refreshed localized copy (C11-291, additions 79 and 83).** Relaunch the sign-off app with `-AppleLanguages` set in turn to `ru`, `uk`, `ja`, `ko`, `zh-Hans`, and `zh-Hant`. Check Feed and a group header in each; in Russian and Ukrainian, check close-other-tabs and close-workspaces counts 1, 2, and 5, plus close-window count 2. In Russian, Ukrainian, and Japanese, show the multiline and send-guard refusals. **See:** checked text is translated, readable, and has no raw placeholders; refusals type nothing and Cancel preserves tabs and workspaces.

23. **[ ] Observe terminal typing while agents run (C11-274, C11-270).** While your logged-in Claude Code or Codex turn is active in the sign-off app, type one short sentence in a plain terminal and read it back. **See:** the sentence is complete; note whether any keystroke visibly lagged or disappeared. This is not a numeric soak result.
