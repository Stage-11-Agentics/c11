## Architecture and files

`scripts/remote-build.sh` is a thin entry to `scripts/remote_build.py`. From an isolated delegator worktree, require initialized, clean Ghostty/Bonsplit at the parent commit's pins. Transfer self-contained parent/module Git bundles, avoiding worktree/submodule gitfile pointers. Union staged/unstaged tracked changes and non-ignored untracked files into an overlay manifest: content hashes, executable modes, symlink targets and deletion tombstones. Exclude Git, Lattice and build/cache outputs. Refuse escaping paths and source mutations during copying.

Use unique invocation payloads beneath `~/c11-builds/<tag-slug>/incoming/`. Cache complete SHA-addressed bundles under `~/c11-builds/bundles`. A predecessor bundle may seed delta transfer through a hard link; rsync uses temp+rename, never `--inplace`. Stable per-tag source directories preserve incremental caches. Remove previously recorded overlays before reset. Fetch parent and modules without recursive submodule fetching, then reset and verify exact pins. The explicit module bundles must supply each pin, rather than asking old bundle origins for historical gitlinks.

Select Xcode 26.3 per process via `DEVELOPER_DIR=/Applications/Xcode-26.3.app/Contents/Developer`; verify version and Zig 0.15.2 from `~/zig-0.15.2`. Overrides may select another path but must report these versions. Never change global Xcode selection, install tools, access keychains, edit launch agents or terminate unrelated processes.

`scripts/atlas_build_slots.py` encloses source preparation, native build/helpers and artifact snapshot. Atin approved two Atlas slots. After one-minute load stays above 40 for 60 seconds, admit new work through slot 1 until load is 40 or lower. Existing jobs finish. Same-tag requests always serialize. Wrap each admitted request with `scripts/with-build-lock.sh` using a slot-specific lock directory. Nested reuse is enabled only in an Atlas slot when the recorded owner is an ancestor. Preserve Hyperion's default single-lock timeout/dead-owner semantics.

All modes require `--tag`. Debug runs `reload.sh --no-launch` with `~/Library/Developer/Xcode/DerivedData/c11-<slug>`. Tests run `test-unit-local.sh test` plus caller selection, with `~/c11-builds/<slug>/derived-test`; require a positive executed test count and `TEST SUCCEEDED`. Release runs `reloads.sh --no-launch` with `~/c11-builds/<slug>/derived-release`, passing `--clean`, `--wmo` and `--universal` when requested. Copy a relative caller-requested xcresult back on test success or failure before returning the native test status. Compilation and assertion status remain separate.

Add `--no-launch` to `scripts/reload.sh` and `scripts/reloads.sh`: perform plist/helper mutations, then final ad-hoc signing and verification, print `APP_PATH`, and exit before CLI pointers/shims, socket writes, quits or app launches. Preserve xcodebuild's pipeline exit code before staging.

Retrieve compressed logs, `result.json` and app snapshots beneath ignored `build-remote/<invocation>/` (add that ignore). Validate source/invocation identity and executable hash before local publication. Debug rewrites daemon HOME/repo-root plist paths to the client, re-signs and verifies, then atomically stages at the usual tagged DerivedData location. Publish the CLI convenience pointer only after successful replacement. Release stages separately. Missing, unusable or wrong-version Xcode/Zig returns exit 3 with result.json and diagnostics retained. Other native/SSH failure returns nonzero, retains previous local apps and cannot launch. `--launch` defaults off and is Debug-only, using `launch-tagged-automation.sh --qa fresh`.
