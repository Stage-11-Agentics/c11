THE CELL AT EVERY SIZE

Exact counts through 99999, then whole thousands. Both slots are sized for five characters, so the envelope never moves as counts grow.

WHAT IS BUILT

The real build (branch c11/mailbox-insights) matches this page: four total tiles, recent rates, 24-hour and 14-day bars, top senders with their unread, top topics, recipients with how many copies were taken, and footnotes when a figure covers only part of the mail. Senders, topics and the urgent, reply, file-body and no-topic counts come from the newest 5,000 envelopes, with a note under them when the mailbox holds more; totals and activity cover every one.

QUESTIONS

  1. Default tab. The drawer still opens on Received. Should it open on Insights instead, or remember the last tab per panel? Recommendation: remember the last tab, so a reader who lives in Insights stays there.
  2. Sent over time. The charts show received only, one series each. A second pair of charts could show sent per hour and per day. Recommendation: add them only if sent volume matters to you; the ledger keeps just the newest 300 sends, so long-range sent history would be thin.
  3. Pickup time. How long mail waits before the agent takes it is probably the most useful health number. The mail files don't carry it, but each claim is recorded as a mailbox.delivered event in the events log. Recommendation: add "median wait" and "slowest wait" in a follow-up that reads those events. It's a bigger read than the mail folders, so it would load a moment after the rest.
  4. Unread edge strip. Unread cards in the Received tab carry a 3 px orange left edge, which your taste rules rule out. Recommendation: replace it with the full-outline treatment in the same follow-up.
