# C11-248: c11: vocabulary rename, workspaces → areas → tabs (pane → area, surface → tab) with hidden aliases

Atin decision 2026-09-30. c11's model is workspaces → areas → tabs: a pane becomes an area, a surface (terminal/browser/markdown leaf) becomes a tab, a sidebar entry is a workspace and is never called a tab. Depth: everything people and agents see (UI text + 7 localizations, CLI commands/flags/help, refs area:N/tab:N, socket methods + JSON keys, env vars C11_AREA_ID/C11_TAB_ID, metadata keys, skills/docs/CLAUDE.md/AGENTS.md) plus c11's own Swift identifiers in Sources/, CLI/, tests. vendor/bonsplit and ghostty internals keep their names; rename only at the c11 boundary. Old names keep working as hidden aliases (commands, flags, refs, env vars). JSON emits new and old keys for one release, old keys marked for removal. tmux-compatible commands (kill-pane, capture-pane, swap-pane, pipe-pane…) untouched. Update consumers: Overwatch launcher, Stage 11 skills, lattice skills. Alias tests + dual-key JSON tests. One CLAUDE.md line states the vocabulary and hidden-alias rule.
