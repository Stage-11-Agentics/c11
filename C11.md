# C11.md: c11

The c11 project file: the mission and working notes for every agent working on c11, on any
harness. It adds to `CLAUDE.md` (how to work in this repo) and never repeats it. The operator sets
the mission; the operator's Chief of Staff keeps the rest current. This repo is public, so the
file holds nothing internal.

One file serves every c11 workspace on this repo, one section each.

work, and get it into outside users' hands. (Confirmed by the operator, 2026-10-27.)

building new primitives that are very bitter lesson build".
