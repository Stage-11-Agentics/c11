## Decisions (closed here)

1. **Two stacks.** Keep `workspaceHistory` and `workspace.last` exactly as they are. Seen-history is a new stack. The grab-list sentence "replace workspaceHistory" would change `workspace.last` from "previous workspace selection" into "previous seen workspace", which breaks AC3. `workspace.last` is not reimplemented on top of seen-history.
2. **Privacy.** Persist only `workspaceId`, `panelId`, `seenAt` (visit start), and `dwell`. Do not persist titles, descriptions, cwd, URLs, scrollback, prompts, tool bodies, metadata, window ids, or area ids. At read time, resolve title, tab type, workspace title, and current `workspace_ref` / `tab_ref` from the live tab. Titles can contain sensitive text, and `c11 tree` / `tab.list` already return the same live title to any socket client; history does not widen that. Resolving live also drops a title after rename. Closed tabs are pruned, so a dead title is never served. Descriptions stay out: they are working context, not needed to go back.
3. **Threshold and cap.** Default dwell **1.0 s**. Cap **200** oldest-dropped. Threshold is injectable on the model. Production reads UserDefaults `focusHistory.dwellSeconds` (clamped to 0.2...30) at store init, not on the key path. No Settings row for the threshold. Document the key in the skill.
4. **Keys.** Back and Forward are new shortcut actions, **unbound by default**. No existing chord moves. Cmd+[ and Cmd+] cannot be assigned to these two actions. No "last seen" toggle and no 10-row history menu (grab-list extras; not in the ticket).
5. **Locales.** English `String(localized:defaultValue:)` only. The six-locale pass is C11-291. Keys are listed below.
6. **List shape.** Completed qualified visits only. The open visit is absent until it ends and meets the threshold. Live "being seen" stays on `tree` / `tab.list`.

## Model

New Foundation-only `Sources/FocusHistoryModel.swift`.

```swift
struct FocusHistoryEntry: Equatable, Codable, Sendable {
    var workspaceId: UUID
    var panelId: UUID
    var seenAt: Date      // visit start
    var dwell: TimeInterval
}

struct FocusHistoryModel {
    static let defaultThreshold: TimeInterval = 1
    static let cap = 200
    var threshold: TimeInterval
    private(set) var entries: [FocusHistoryEntry]  // oldest → newest
    private(set) var index: Int?                    // nil if empty
    // open visit + suppressLanding are not persisted
}
```

`noteSeen(workspaceId:panelId:at:)` is called only when the seen panel changes (including to nil).

- Same non-nil panel as the open visit: return. No allocation beyond the existing open tuple.
- Leaving a panel (to another panel or to nil): `dwell = now - startedAt`. Drop the open visit.
  - `dwell < threshold`: discard.
  - `suppressLanding` and this panel is `entries[index]`: discard. Do not update dwell. Do not truncate. Leave the flag set. This is the tab back/forward just landed on.
  - Else if this panel is `entries[index]`: replace that entry's `seenAt` and `dwell`. Do not append. Do not truncate. Consecutive re-looks stay one entry.
  - Else: clear `suppressLanding`. Delete entries after `index`. Append. `index` = last. While `count > cap`, `removeFirst` and decrement `index`.
- Opening: if `panelId != nil`, start an open visit at `now`. A nil `workspaceId` with a non-nil panel is treated as nil (cannot name a target).

`prepareForNavigation(at:)` runs **before** the index moves. It closes the open visit through the rules above, preserving the existing `suppressLanding` value. On the initial navigation from a normal visit it is false; on a repeated navigation from a previous landing it is true and that landing is discarded without modifying the branch. Do not reset it before closing the visit. An under-threshold glance is abandoned. A boundary/no-op navigation preserves an ongoing seen visit, or explicitly restarts it at the same transition time, so one failed step does not stop future dwell recording.

`back(isLive:)` / `forward(isLive:)`:

- Walk from `index` in that direction. `remove` entries whose panel fails `isLive`. Do not reopen anything.
- Land on the first live entry, set `index`, set `suppressLanding = true`, return the entry.
- None left: return nil, do not move `index` (it may now be nil if everything was pruned). Empty and boundary are not errors inside the model; the socket maps nil to `not_found`.

`prune(panelId:)` first discards any matching open visit, then removes all matching completed entries. Preserve the current entry's identity when removing an earlier row; if the current entry is removed, choose the nearest remaining earlier entry (or the first survivor, or nil when empty). Clear a matching suppressed landing. This prevents the close-triggered seen transition from re-appending a dead panel and prevents unrelated pruning from moving the cursor.

Persisted payload is `FocusHistorySnapshot { entries, index }` without the open visit or the suppress flag. `index` past the end clamps on decode.

## Feed, off the key path

`Sources/FocusHistoryStore.swift`, `@MainActor`, one shared instance.

`TabSeenTracker.refresh()` already returns before any work when the seen panel is unchanged (line 142). On a real change, after `clock.observe`, call `FocusHistoryStore.shared.noteTransition(panelId:seen, at:now)`. The store resolves the workspace by scanning main-window contexts for that panel UUID. No disk I/O. No call from `hitTest`, `WorkspaceRowView`, or `forceRefresh`. No per-key sample.

Interruptions (lock, screensaver, display sleep, system sleep, session resign) already flow through `refresh()` with `seen == nil` (`TabSeenClock.swift:140–148`). The visit ends at interruption start, so sleep time is not dwell. Unlock starts a new visit; two 0.4 s looks split by a lock do not combine. Background socket focus leaves `operatorSeenPanelId()` nil, so it does not open a visit. A foreground socket change that really changes the seen tab can qualify. Do not inspect command provenance.

`prepareForNavigation` + `suppressLanding` are set inside the store **before** `focusPanel`, so the refresh caused by the navigation itself cannot truncate the forward branch.

## Locate and focus

On back, forward, list, and restore, find the panel by UUID across `AppDelegate` main-window contexts. If it now lives in a different workspace, rewrite `entry.workspaceId`. If it is gone, prune it.

`history.back` and `history.forward` go in `TerminalController.focusIntentV2Methods` (`TerminalController.swift:252–267`). `history.list` does **not**. Socket policy then suppresses app activation (`shouldSuppressSocketCommandActivation`) and allows in-app selection. The handler uses the existing `v2MaybeFocusWindow` + `v2MaybeSelectWorkspace` + `Workspace.focusPanel(_:)` (`Workspace.swift:9503`). No new `NSApp.activate` and no `bringToFront`. Match `tab.focus`. Do not change `v2WorkspaceLast`.

## Socket and CLI

New `Sources/SocketHandlers/HistoryHandlers.swift`. `history.back`/`history.forward` route from `v2DispatchExtracted` on prefix `history.` (`SocketDispatch.swift:994`), with main execution justified by AppKit selection. `history.list` joins `TerminalController.socketWorkerV2Methods` AND the `socketWorkerV2Response` switch (`SocketDispatch.swift:56`): the default extracted dispatcher already runs on main, so putting parsing there would not be off-main. Parse the list limit on the worker; use one bounded main hop for the exact live snapshot. Add all three methods to `v2Capabilities()` (`SystemHandlers.swift:54`).

| Method | Focus intent | Work |
|---|---|---|
| `history.list` | no | Parse `limit` off-main. `v2MainSync` only to copy entries and resolve live refs. Does not focus, does not `noteSeen`, does not mark seen. |
| `history.back` | yes | `prepareForNavigation`, step, then in-app focus. |
| `history.forward` | yes | same |

`limit` default **50**, max **200**. Omitted `limit` uses 50; a supplied null/non-integer, `< 1`, or `> 200` → `invalid_params`, message `limit must be an integer from 1 to 200`. List returns the **tail** of that many entries, oldest→newest inside the tail (the recent trail Overwatch reads). `back`/`forward` with `limit` or `json` as a navigation modifier: `limit` on those verbs is `invalid_params` (`limit applies to history listing`). `--json` on back/forward is allowed and returns the destination entry.

List JSON (also the human command's `--json`):

```json
{
  "threshold_seconds": 1.0,
  "cap": 200,
  "total": 37,
  "position": 36,
  "back_count": 36,
  "forward_count": 0,
  "entries": [{
    "workspace_id": "UUID",
    "workspace_ref": "workspace:2",
    "workspace_title": "c11",
    "tab_id": "UUID",
    "tab_ref": "tab:12",
    "title": "Focus History Grok",
    "type": "terminal",
    "seen_at": "2026-10-01T22:00:00Z",
    "dwell_seconds": 2.0,
    "current": true
  }]
}
```

`seen_at` uses `ISO8601DateFormatter()` with the default seconds format, same as `last_seen_at` (`SurfaceHandlers.swift:11–19`). `dwell_seconds` is rounded to milliseconds. `position` is the cursor in the **full** stack (`null` when empty); `current` is true only on the entry that is that cursor, if the tail includes it. `back_count` / `forward_count` describe the full stack so a short tail still says whether back/forward will move. Empty list is success: `entries: []`, `total: 0`, `position: null`, counts 0. Human text: `No focus history.`

Human list, same order, one line per entry: `tab:12  <title>  2.0s  <seen_at>` with `  ←` on the current row when it is in the window. A one-line header: `<total> entries, showing <n>, position <position|none>`.

Back/forward success returns the destination entry (human: `tab:12  <title>`; json: that object plus `position`). Failure: `No earlier focus history entry` / `No later focus history entry`, socket `not_found`, CLI exit 1. Dead targets are skipped inside the step; if none remain, the same not-found result.

- Dispatch history after authentication but BEFORE the global `--window` focus preamble (`CLI/c11.swift:1950`). - `subcommandUsage` and the command list in `usage()` (~17881).
- `--json` is already global (1719) and must also be accepted after the verb, same as `brand`.
- Verbs: `c11 history [--json] [--limit N]`, `c11 history back [--json]`, `c11 history forward [--json]`.
- No hidden alias. Do not touch tmux `!` / `workspace.last` (`c11.swift:15303`).
