# C11-155: AgentDetector bun-runtime support for omp/pi auto-resume detection

Surfaced during C11-154 (omp exact-resume). bun-installed omp and pi run as "bun /path/<tui>", so AgentDetector.classify (ps comm=bun) matches neither detectComms (omp/pi) nor the node-gated detectNodeArgsSubstrings (@oh-my-pi/, @earendil-works/pi) -> terminal_type tagged unknown. AgentDetector is the SOLE writer of terminal_type (no spawn-time tag), so factory-launched bun-omp/pi never get the right type and the correct, shipped C11-153/154 resume rails never fire unless terminal_type is set manually. FIX: teach AgentDetector to handle the bun runtime (mirror the existing node branch) and/or match the TUI shim basename - covers omp + pi together. The resume strategies (PiStrategy/OmpStrategy) are correct and merged; this is detection-only. Acceptance: a bun-installed omp/pi process classifies to terminal_type=omp/pi; live auto-resume fires end-to-end without a manual override.
