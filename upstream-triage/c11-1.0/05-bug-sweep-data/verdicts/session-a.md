## Top findings

**Terminal close remains the strongest match to a known c11 hang.** #5316 moves native teardown off main, whereas c11 still frees Ghostty surfaces on MainActor. This is the join edge in [the August 25 deadlock note](/Users/atin/Projects/Stage11/code/c11/notes/2026-08-25-freeze-surface-deinit-deadlock.md). A read thread blocked on the shared 64-slot mailbox cannot finish while main joins it. However, the note explicitly says off-main free violates this engine's threading contract. Use the finding to prioritize abortable mailbox pushes or a proven engine upgrade. The Swift worker is not a safe standalone cherry-pick.

**Quit also has an independent telemetry lock inversion.** #6232 removes the synchronous PostHog flush. c11 still calls it during applicationWillTerminate and waits on the analytics work queue. Upstream identifies SDK work that can wait for main, completing the cycle. The synchronous edge is confirmed in c11; occurrence depends on enabled telemetry and SDK timing. This is not evidence for the unspecified July 28 deadlock.

**Notification churn still invalidates the whole sidebar.** #5859 isolates an equality-guarded unread projection; c11 observes TerminalNotificationStore directly. Forty agents can repeatedly dirty every sidebar row even when unread state is unchanged. #6886 separately reduces notification-list row work and repeated workspace-title searches. These findings match known problem 2's broad invalidation pattern. Their contribution to any specific captured AttributeGraph or metadata-lock stall is inferred, not measured.

**Claude hooks repeatedly scan transcripts with no size bound.** #5202 bounds the tail read, while c11 reads the entire file, copies it into a String, and splits every line on Stop. Cost grows with session length and concurrent agents. #2462 adds a separate bounded-input opportunity. #8537 also shows why the existing C11-156 fix is incomplete for prompt latency: several sequential socket calls each permit as much time as the enclosing hook's entire deadline.

**Restore and launch have concrete smaller failure modes.** #2469 can suppress restoration before validating an explicit-open event. #3980 replaces an initial hardcoded 50/50 animated split with the configured ratio. #7010 prevents two wrapper directories from repeatedly execing one another. These are more actionable than the conditional macOS 27 symbol crash and cwd-drift findings, whose c11 runtime triggers remain inferred.
