c11 tab sheet, round three

The count cell now appears on every tab bar, including the right area, where all the tabs fit. Click either one. Every column has a fixed width, so nothing moves when titles, agents or statuses change length. Drag rows by the grip on the far right.

The grid

  • Columns: Tab N · mark · title / subtitle (the only flexible column) · agent 150pt · status 104pt · clocks 78pt each · close · grip.
  • Line 1 is the scan line: title, agent tag, status, clocks. Line 2 is the subtitle, spanning the title, agent and status columns.
  • An empty cell shows —; it never collapses. Long text truncates inside its own column.
  • The visible tab has a bold title, a gold Tab N, and a gold left rule.

Clocks

  • Active: time since the tab last produced output or an agent last wrote to it. Launched: time since the tab opened. Seen comes with its own ticket.
  • One ordered list sets the order, e.g. active,seen,launched. It's read from a single c11 setting that an agent can change.

Agent tag

  • Shows harness · model for Claude Code, Codex, Pi and OMP, from c11's existing agent identity (launch-agent, set-agent, the session wrappers).
  • If the model is unknown, it shows the harness alone. If there's no agent, it shows —.
