# C11-195: launch-agent: project .c11/agents.json lookup uses the app process cwd on the default path

Found during the C11-193 trident plan review (pack: notes/trident-review-C11-193-plan-pack-20260806-1200/). v2AgentLaunch computes `let lookupCwd = cwdOverride ?? FileManager.default.currentDirectoryPath` (Sources/SocketHandlers/SocketDispatch.swift:~1073) and uses it to locate .c11/agents.json via DefaultAgentProjectConfig.find(from:). The fallback is the c11 APP PROCESS's cwd — for a GUI app essentially arbitrary — so project-level agent configuration is silently never applied on the default (no --cwd) launch path. The same pattern reportedly appears in defaultAgentLaunch in TerminalController.swift (~9074). Root cause is shared with C11-193/C11-194: the launching surface's cwd is never plumbed to the server. C11-194's centralized cwd resolution is the natural fix point — the lookup should use the resolved effective launch cwd, not the process cwd. Verified against the working tree by two independent reviewers plus the synthesis pass.
