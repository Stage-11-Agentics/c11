THE CELL AT EVERY SIZE

Exact counts through 99999, then whole thousands. Both slots are sized for five characters, so the envelope never moves as counts grow.

DRILL-DOWN

Every sender, topic and bar is a filter. Picking one narrows the whole tab to that slice: the tiles, both charts, the other rankings, and a list of that slice's newest messages underneath. Filters stack, one per kind: a sender and a topic and a time (an hour or a day). The chip row at the top always holds its height, so the layout never jumps when a filter comes or goes. With a filter on, the fourth tile shows the slice's share of all mail instead of the sent count.

PICKUP WAIT

How long mail waits in this inbox before the agent takes it. Each claim (c11 mailbox recv --ack, or a hook drain) appends a claimed row to the workspace's mailboxes/_dispatch.log with the claim time and the recipient panel. The wait is that time minus when the message landed in this inbox (the later of its ULID time and the file's time). Only this panel's own rows count, so a broadcast's copies in other inboxes never mix in.

The section follows every received filter: pick a sender, topic, hour or day and the figures cover only that slice's taken messages. Median, p90 and slowest; the claim count and the window (claims in the last 14 days); a five-step distribution with a fixed height; and the median per sender for the four senders with the most claims, padded to the same row count when a filter narrows them.

The log is read off the main thread: the last 8 MiB at most on the first look, then only the bytes appended since, cached by file offset. Mail taken before claim rows existed (c11 1.7.5) has no pickup time, and the section says how many taken messages that leaves out. A from chip offers Open conversation, which switches to the Conversations tab on that sender's thread.

DECISIONS

  1. Sample. Senders, topics and every drilled figure come from the newest 5,000 messages; a note says so when the mailbox holds more. Parsed headers are cached, so reopening and clicking are fast.
  2. Message list. A slice lists its newest 50 messages.
  3. Recipients. "Sent to" rows are clickable and show what this panel sent there and whether each copy was taken.
  4. Pickup source. Claim rows in the workspace dispatch log, not mailbox.delivered in the events log: they name the exact recipient panel, carry the claim time itself, and are written even with activity history off.
